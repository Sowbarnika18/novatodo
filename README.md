# 🚀 NovaTodo - Smart Task Manager

A modern, AI-powered todo application with voice input, smart priority detection, and beautiful UI.

## ✨ Features

- **Smart Priority Detection**: AI suggests priority based on task content
- **Voice Input**: Add tasks using your microphone
- **Dark/Light Theme**: Automatic theme switching with local storage
- **Drag & Drop**: Reorder tasks easily
- **Real-time Stats**: Track productivity with visual dashboard
- **Categories & Due Dates**: Organize tasks effectively
- **Search & Filter**: Find tasks quickly
- **Keyboard Shortcuts**: Power user friendly
- **Local Storage**: Data persists in your browser

## 🛠️ Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with CSS variables, animations, and glass-morphism
- **JavaScript ES6+** - Pure JavaScript, no frameworks
- **Font Awesome** - Icon library
- **Google Fonts** - Inter font family
- **Web Speech API** - Voice recognition
- **LocalStorage API** - Data persistence
